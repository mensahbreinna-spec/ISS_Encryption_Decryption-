 ISS Encryption and Decryption

 Project Description
This project is a simple encryption and decryption program developed using Visual Basic.

It uses the Caesar Cipher technique, where each character in a message is shifted by three positions during encryption and shifted back by three positions during decryption.

Programming Language
Visual Basic (VB.NET)

 Features
- Accepts a message from the user.
- Encrypts the message by shifting characters forward by 3.
- Decrypts the encrypted message by shifting characters backward by 3.
- Displays both the encrypted and decrypted messages.

Example
Input: HELLO

Encrypted Message: KHOOR

Decrypted Message: HELLO
